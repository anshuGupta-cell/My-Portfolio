📂 **Repository:** [github.com/anshuGupta-cell/My-Portfolio](https://github.com/anshuGupta-cell/My-Portfolio)

---

## ✨ Features

- **Responsive Navigation & Smooth Scrolling:** Seamless navigation across *Home*, *About Me*, *Services*, *My Work*, and *Contact Me* on both desktop and mobile viewports.
- **Hero Section & Resume Download:** Direct quick-access actions to connect or download my latest resume (`PDF`).
- **About & Technical Toolkit:** Highlights my educational background (TYBCS), core programming languages, and everyday development tools.
- **Services Showcase:** Outlines capabilities across Frontend, Backend, and Full-Stack Web Development.
- **Featured Projects Gallery:** Curated showcase with direct live deployment links.
- **Interactive Contact Section:** Built-in contact form with toast notifications for user feedback.
